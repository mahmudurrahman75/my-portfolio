## 6. Data-Driven Architecture

This is a critical requirement.

Store all portfolio content in separate JSON files instead of hardcoding personal information inside React components.

Create a structure similar to:

src/
  assets/
  components/
    layout/
    sections/
    ui/
  data/
    personal.json
    navigation.json
    skills.json
    projects.json
    experience.json
    education.json
    entrepreneurship.json
    socialLinks.json
  hooks/
  types/
  utils/
  App.tsx
  main.tsx
  index.css

Adapt this structure to the existing project instead of blindly replacing it.

Requirements:
- Use TypeScript interfaces or types for the JSON data.
- Create reusable components.
- Keep layout and presentation separate from content.
- Avoid duplicated content.
- Use semantic HTML.
- Use reusable buttons, section headings, badges, cards, and timeline components.
- Keep data easy to update without modifying the UI.
- Store image paths and external links in data files when appropriate.
- Validate data assumptions and handle optional fields safely.

Because this is a static React portfolio, do not introduce a backend or database unless explicitly required.
